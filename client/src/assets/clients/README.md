# Client logos

Drop a client's logo in this folder and the Clients page uses it automatically.
No code changes needed.

**File name = the slug below, with .svg, .png, .webp or .jpg**

| Client                | File name                          |
| --------------------- | ---------------------------------- |
| Aberdare Cables       | `aberdare-cables.svg`              |
| Manitou SA            | `manitou-sa.svg`                   |
| LiuGong Machinery SA  | `liugong-machinery-sa.svg`         |
| International Trucks  | `international-trucks.svg`         |
| Freightliner          | `freightliner.svg`                 |
| Insimbi Group         | `insimbi-group.svg`                |

Tips
- Prefer SVG (sharp at any size). If PNG, use a transparent background, at least 600px wide.
- Get logos from the client themselves (their brand/press kit or marketing contact), and get their OK to show them.
- To hide a client from the page, set `show: false` for them in `pages/ClientsPage.tsx`.
